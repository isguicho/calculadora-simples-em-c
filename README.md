# calculadora-simples-em-c
Calculadora básica em linguagem C desenvolvida para prática de lógica com operações aritméticas fundamentais.

## 💻 Tecnologias Utilizadas
* Linguagem C
* OnlineGDB (ou qualquer ambiente de compilação que suporte linguagem C)

## 🚀 Como Executar o Projeto
1. Acesse o site [OnlineGDB](https://www.onlinegdb.com) (ou qualquer outro compilador de C online ou local).
2. No canto superior direito, clique no menu de linguagens e selecione a opção **C**:
   <img width="230" height="508" alt="escolherCprint" src="https://github.com/user-attachments/assets/85915c60-532d-4d08-9106-aa527e1bf26c" />

3. Copie o código do ficheiro `main.c` deste repositório e cole na área de edição principal do site.
4. Clique no botão verde **Run** localizado na barra superior para iniciar a compilação:
   <img width="689" height="756" alt="botaorunCprint" src="https://github.com/user-attachments/assets/b2248873-5387-4ad2-9938-087629caba4f" />

## 🧮 Como Utilizar a Calculadora
1. Após iniciar o programa, clique na consola preta na parte inferior da tela.
2. Utilize o teclado para digitar o primeiro número, o segundo número e escolher a operação matemática desejada (1 para Soma, 2 para Subtração, 3 para Multiplicação ou 4 para Divisão).
3. O cálculo será processado e o resultado será exibido imediatamente na consola:
   <img width="406" height="269" alt="consoleCcalculadoraResultado" src="https://github.com/user-attachments/assets/84d7ed08-604d-4604-9dce-1ee4590c5617" />
